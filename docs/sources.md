# 외부 표준 — 출처와 원문 대조 기록

규칙 파일에서 인용한 외부 표준의 목록이다. **✔ 원문 대조**는 원문(법령 조문·PDF 본문·웹 원문)을 직접 읽고 쪽수까지 확인한 것, **◐ 2차**는 색인·해설로만 확인한 것이다. 규칙 본문에는 ✔만 원문 근거로 쓴다. 원문 파일은 이 저장소에 넣지 않았다(공공저작물도 자료마다 이용 조건이 다르다) — 아래 링크에서 받는다. 확인일 2026-09.
